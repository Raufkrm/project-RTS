What is WGPU and why are we using that one


WGPU is the Rust-native implementation of WebGPU—the new, cross-platform GPU API that sits roughly in the same space as Vulkan, DirectX 12, and Metal. It exposes modern explicit graphics/compute features but keeps a consistent, safe interface across desktop, mobile, and web targets.

In Bevy 0.18 (which your project tracks), WGPU is the rendering backend baked into Bevy’s renderer. Using Bevy automatically means the engine drives WGPU under the hood to compile WGSL shaders, create pipelines, manage bind groups, etc. That’s why the validation errors you’re seeing mention “wgpu”; they’re coming from Bevy’s renderer telling us our shader/BindGroup layouts don’t line up with what WGPU expects.
